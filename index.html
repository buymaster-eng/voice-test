声で記録の試し（Android の Chrome 用）

開いたらすぐ聞き取りを試みます。始まらない時は丸いボタンを押して「A社の請求書づくり開始」のように話してください。話し終わると自動で送信され、画面に出ます（声の復唱は、画面を一度押した後に鳴ります）。これは試しの画面で、記録はどこにも保存しません（画面を閉じると消えます）。

ボタンを押して話してください

理由と直し方（うまく動かない時・Android）
  1. マイクの確認で「許可しない」を押した時：Chrome の右上の「︙」→「設定」→「サイトの設定」→「マイク」→ ブロック中の一覧からこのページを選び「許可」にして、このページを開き直す
  2. それでも確認が出ない時：スマホの「設定」→「アプリ」→「Chrome」→「権限」→「マイク」を「アプリの使用中のみ許可」にする
  3. LINE やメールの中で開いた時：右上の「︙」から Chrome で開き直す（アプリの中の画面では使えないことがあります）
  4. 理由の記号が service-not-allowed か language-not-supported の時：この機種の Chrome では声の聞き取りが使えない状態です。下の予備（キーボードのマイク）で試すか、次の入口へ進んでください

画面の名前は、機種や Chrome の版で少し違います。

予備：キーボードのマイクで話す（話し終わって2秒たつと自動で送信し、キーボードを閉じます。声の復唱はしません）
